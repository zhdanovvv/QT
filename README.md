Небольшие собственные проекты, разработанные в Qt Creator.

BlackPill_STM32F411CEU6: 
    Прошивка на С/C++ с USART логерром, CMSIS + HAL. Инструкции по сборке и получению логов внутри директории проекта, docs/readme.txt.

http_client: 
    Cкачивает .exe файлы небольшого размера c сервера. Скачивание происходит в отдельном от GUI потоке. Проект достаточно открыть в Qt creator собрать и запустить. Рассчитан на Windows 10,
    но работает и в Linux.
